# 任务清单：动量策略改进实验

## 背景与问题

最新一次宽池回测（`docs/BROAD_ETF_200_BIWEEKLY_TOP3_20260630.md`，253 只 ETF，2023-06-30 ~ 2026-06-30，双周 top3，**已去掉 MA120 趋势过滤**）：

| 指标 | 动量策略 | 基准(全池等权,剔黄金) |
|---|---:|---:|
| 总收益 | 104.6% | 75.9% |
| CAGR | 28.2% | 21.7% |
| 年化波动 | 33.3% | 22.5% |
| 最大回撤 | **-38.7%** | -25.3% |
| 夏普 | **0.91** | **0.99** |
| Calmar | 0.73 | 0.86 |

**核心问题：绝对收益不低（28% 年化），但风险调整后打不过"全池等权躺平"——夏普 0.91 < 0.99，Calmar 0.73 < 0.86，最大回撤还高出一截（-38.7%）。**
目前这套动量本质是"高风险版的全市场 beta"，没有产生真正的 alpha。

## 改进目标（验收标准）

- **首要目标：策略夏普稳定 > 基准 0.99，且最大回撤明显小于 -38.7%。**
- 次要目标：Calmar > 基准 0.86。
- 不以牺牲风险指标去单纯堆绝对收益；每个实验都要和同区间基准对比 CAGR / 波动 / 最大回撤 / 夏普 / Calmar。

## 实验清单（按预期收益排序）

### P0 — 控回撤（预期最有效）

- [x] **加回 MA120 趋势过滤**：对比"有过滤 vs 无过滤"两版。重点看回撤能否从 -38.7% 大幅下降、夏普能否回到 0.99 以上。这是上次特意去掉的旋钮，是回撤飙高的直接原因。`docs/P0_TREND_CASH_EXPERIMENT_20260630.md` 结论：未达标，MA120 + cash 夏普 0.901、最大回撤 -38.72% `(codex)`
- [x] **空仓切现金/货币基金**：当合格标的不足 top_k（被趋势过滤剔光）时，剩余权重放货币基金（`configs/universe.yaml` 里已有 `511880`，当前 `enabled: false`，需启用）或现金（年化 1.5%）。熊市不硬扛。已选择现金口径，未启用 `511880`；缺口权重留现金并按年化 1.5% 计息 `(codex)`

### P1 — 分散，降集中度风险

- [ ] **放宽到 top5**：当前 top3 过度集中（最新信号 3 个全是半导体）。对比 top3 / top5 / top8 的风险调整表现。
- [ ] **单类别持仓上限**：同一 bucket/类别最多选 N 只（如最多 2 只），避免整组押在同一赛道（如全是银行或全是半导体）。
- [ ] **降低 `max_weight`**：当前 0.50，试 0.34（≈等权）对比波动与回撤。

### P2 — 信号本身

- [ ] **关掉 `volatility_adjusted` 对照**：看不做波动率惩罚时，进攻品种回归后收益/风险如何变化。
- [ ] **缩短 lookback 权重**：当前偏中长周期（60/120 日权重 0.7）。试更偏短中期（如 20/60 为主），看是否更跟得上轮动、回撤是否改善。
- [ ] **调仓频率对照**：weekly / biweekly / monthly 三档对比，权衡交易成本与跟踪及时性。

### P2 — 信号有效性诊断（回答"动量到底有没有用"）

> 与 `docs/METRICS_TODO.md` 第五节呼应，先把这些算出来再调参，避免瞎调。

- [ ] **IC / ICIR**：每个调仓日动量得分 vs 下一期收益的横截面 Spearman 相关，输出均值与 ICIR。
- [ ] **分组单调性**：按得分分 N 组，检验高分组收益是否单调高于低分组。
- [ ] **多空价差**：Top 组收益 - Bottom 组收益，确认动量因子方向是否真的有效。
