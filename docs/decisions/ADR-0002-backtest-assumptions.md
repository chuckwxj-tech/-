# ADR-0002：回测假设

- 状态：Accepted
- 日期：2026-06-30

## 决策（所有回测必须遵守）

- **执行**：next-bar 开盘成交。信号用 T 日数据生成，最早 T+1 开盘成交。**绝不在产生信号的当根收盘价成交。**
- **费用**：佣金默认 2.5 bps；滑点默认 5.0 bps（见 `configs/costs.yaml`）。
- **现金**：默认初始 100 万；空仓现金年化 1.5%（货币基金代理）。
- **停牌/缺失**：缺价格的标的当期不可交易，显式跳过，不静默用前值穿越。
- **上市时间差**：接受稀疏面板，ETF 上市前不参与打分与持仓。
- **年化系数**：252 个交易日；无风险利率默认 0。
- **基准**：每份策略报告必须附**同区间基准**（默认：有效池等权、剔黄金）对比 CAGR/波动/最大回撤/夏普/Calmar。
- **可复现**：落盘配置、参数、日期范围、包版本、运行时间（`artifacts/records`）。

## 红线

- 不实现实盘交易。
- 任何引入未来函数、数据泄露的改动一律不合并。
