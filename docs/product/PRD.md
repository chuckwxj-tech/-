# PRD：A 股 ETF 周频动量轮动系统

## 一句话

用动量信号在一篮子 A 股 ETF 中周频/双周轮动，输出**手动调仓清单**和**带风险指标的回测报告**。第一阶段不做自动交易。

## 用户与场景

- 单一使用者（项目所有者），每周按系统生成的调仓清单手动下单。
- 需要可复现、可审计的回测，能判断策略是否真的优于"全池等权躺平"基准。

## 范围（第一阶段）

包含：
- 统一数据层（ETF 日线 OHLCV，缓存，质检）
- ETF 池管理（行业/主题/宽基分类，成交额/规模过滤）
- 动量打分（多周期动量 + 波动率惩罚 + 趋势过滤）
- 风控（单标的上限、同主题上限、回撤/趋势防守、现金/防守仓）
- 回测引擎（next-bar 开盘成交，费用+滑点，停牌/缺失处理）
- 业绩指标（CAGR / 波动 / 最大回撤 / 夏普 / Sortino / Calmar / 换手 / 胜率，+ 同区间基准）
- 信号有效性诊断（IC / ICIR / 分组单调性 / 多空价差）
- 手动调仓清单 + 每周 signal 生成 + 策略对比报告

不包含（明确排除）：
- 自动下单、券商接口、实盘执行
- 高频 / 日内
- 衍生品

## 成功标准

- 回测**无未来函数**、可复现（配置/参数/区间/版本/时间落盘）。
- 策略风险调整后**稳定优于全池等权基准**（夏普、Calmar），否则结论就是"不如躺平"。
- 每周能一键产出手动调仓清单。
