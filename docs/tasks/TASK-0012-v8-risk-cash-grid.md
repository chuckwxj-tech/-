## 背景

V8 将既有 SOXX/SMH 风险/现金比例研究迁移到实际 A 股 ETF 菜单，用于展示不同风险比例的历史取舍。结果只提供研究输入，不选择或推荐“最佳”比例。

## 目标

在固定菜单、固定成本与固定执行时点下，比较风险权重、再平衡阈值、静态不再平衡对照及触发器 A/B，并产出可复核的数据、指标和验证记录。

## 输入

- 风险腿：`588170 / 159781 / 515050 / 588200`

- 现金腿：`511990`，使用官方每日百份收益，不使用价格仿射调整
- 风险权重：`60 / 65 / 70 / 75 / 80 / 85 / 90 / 100`
- 再平衡阈值：`±2 / ±3 / ±4` 个百分点
- 交易成本：佣金 `2.5bp`、最低 `5元`，滑点 `2bp`
- 信号与成交：`T` 日收盘生成信号，`T+1` 日收盘成交
- 样本：
  - 短样本：自 2020-01 起，四条实际指数分别拼接 ETF 总收益
  - 长样本：自 2011-07-22 起，使用已披露的低置信度代理
  - 纯实盘样本：自 2025-04-08 起，仅用于一致性检查
